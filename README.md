## Open source

**[NetworkKit](https://github.com/nnirajan/NetworkKit)** · Swift Package · iOS 16+ · macOS 13+

A lightweight networking library built on URLSession for REST APIs. It handles authentication, retry, logging and validation without the weight of a full framework.

![async/await](https://img.shields.io/badge/async%2Fawait-F54A2A?style=flat-square&logo=swift&logoColor=white) ![Token-refresh retry](https://img.shields.io/badge/Token--refresh_retry-555555?style=flat-square) ![Interceptors](https://img.shields.io/badge/Interceptors-555555?style=flat-square) ![XCTest suite](https://img.shields.io/badge/XCTest_suite-555555?style=flat-square)

```swift
import NetworkKit

let client = NetworkClient(
    configuration: NetworkConfiguration(
        baseURL: URL(string: "https://api.example.com/")!
    )
)

let users: [User] = try await client.execute(UserRequest.list)
```
